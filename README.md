## v6.1.4 (2026-11-24) — 건축 1차 교차검증 반영(A-09 승인 ②)

- [필수] 무효 입력(용도지역 · 유형 미선택, 높이 0 · 빈 값, 측정 높이 > 건물 높이, 음수 거리) 때 직전 결과 · 요약 스트립 · A4 를 지움(A4 「검토를 먼저 실행하세요」, 인쇄 · JPG 막음).
- [필수] 개정 기준(적용 기준일 2026. 11. 12. 이후) 판정 · A4 근거를 「건축법 제61조① 정북 사선 · 시행령 제86조 ③1호 채광 …」 · 3절 「법 제61조 제1항 · 시행령 제86조 제3항」으로 표기(영 §86① 삭제 반영). 종전 기준 표기는 그대로.
- [필수 · 결정] 영 §86③ 본문 단서 — 채광 행 · 공동주택 안내에 「다세대주택은 1m 이상으로서 조례 거리(예: 익산 §36⑦ 2m) 이상이면 채광 적용 제외」 안내. 자동 면제 · 조례 거리 입력은 하지 않음.
- [결정] 익산시 건축조례 §36①이 개정 전 문구(영 제86조제1항 · 10m 초과 1/2)로 남아 있음 — 개정 기준 화면 · A4 에 「조례 확인 · 허가권자 확인」 안내만. 계산 불변.
- [필수 · Codex 회귀] 선택 거리 칸(채광창 이격 · 동 간 거리 · 제6항 너비)에 음수를 넣어도 결과 · 요약 · A4 를 지우고 「거리 값은 0 이상」 안내(종전 0 으로 흡수).
- [권장] A4 최신성 — 검토 뒤 입력이 바뀌면 A4 맨 위 「입력이 바뀌었습니다 — 다시 검토하세요」.
- [권장] 특례 3호 이름(건축협정에 일정 거리 이상 띄어 건축하는 내용이 있는 경우만) · 동 간 거리 조례(예: 익산 §36⑧ 1배 · 도시형 0.6배) · ③2호 나목 10m 안내 · 법 §61③(정남 특례 고시 높이) · ④(2층 · 8m 이하 조례 적용 제외) 안내 · A4 「경계선까지 거리」 / 「유효 이격(제6항 반영)」 분리.
- [권고] ⑥ 선택지(자동차 전용도로 · 유원지 · 공원 제외 요건 · 소규모 대지 요건) · 채광창 이격 칸 ⑥ 안내 · 죽은 코드(shareNative · copyLink · fallbackCopy · buildA4Doc · 첫 openA4Preview) 삭제 · README · 화면 하단 시행일 2026. 11. 12.
- 계산값 · 판정 불변(예제 A~D · 경계 시나리오 전후 같음). 공통 원본 MM-PRINT · MM-PROJECT 구간 무변경. sw 캐시명 `jiljo-v6.1.4`. 사용자 매뉴얼은 다음 회차.

## 파일 구조

```
├── index.html          # 앱 본체
├── manifest.json       # PWA 매니페스트
├── sw.js               # Service Worker (Cache-First)
├── manual/             # 사용자 매뉴얼 (index.html · PDF · images · _tools 재현 스크립트)
├── icons/              # 앱 아이콘 (16px ~ 512px)
│   ├── favicon.ico
│   ├── apple-touch-icon.png
│   ├── icon-maskable-512x512.png
│   └── icon-{N}x{N}.png
└── .github/workflows/
    └── deploy.yml      # GitHub Pages 자동 배포
```
